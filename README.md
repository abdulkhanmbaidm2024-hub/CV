# CV – Abdul Khan Mbaidm

A clean, responsive single-page CV built with plain HTML and CSS — no frameworks or build steps required.

## 📄 Preview

Open `index.html` directly in any browser, or host it on GitHub Pages for a public URL.

## ✏️ Customise

Edit `index.html` and update the placeholder values:

| Placeholder | Replace with |
|---|---|
| `abdulkhan.mbaidm@email.com` | Your real email address |
| `+1 (555) 000-0000` | Your phone number |
| `Your City, Country` | Your location |
| Job titles, dates, descriptions | Your actual experience |
| University name, GPA, dates | Your actual education |
| Project names & links | Your real projects |

## 🖨️ Print / PDF

Open `index.html` in Chrome or Firefox, press **Ctrl + P** (or **⌘ + P** on Mac), and choose **Save as PDF**.
